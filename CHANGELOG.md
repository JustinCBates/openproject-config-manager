# Changelog

All notable changes to the OpenProject Config Manager will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [2.0.1] - 2025-10-16

### Added
- Automated build and release workflow via GitHub Actions
- Three-tier branching strategy (develop → build → main)
- Package distribution via GitHub Releases
- CHANGELOG.md to track version history

### Changed
- Improved CI/CD pipeline for automated package building

## [2.0.0] - 2025-10-16

### Added
- Interactive configuration management
- Intelligent discovery and live validation
- Dual-mode support (Development & Production)
- Docker Compose project configuration
- Comprehensive configuration validation
- Production deployment support

### Features
- Real-time configuration validation
- Docker Compose integration
- Interactive TUI for configuration management
- Production-ready configuration templates

## [1.0.0] - Initial Release

### Added
- Basic configuration management functionality
- Docker Compose support
- Initial validation system
